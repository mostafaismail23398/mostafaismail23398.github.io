# Mostafa Ismail Ahmed — Portfolio + Content Dashboard

A responsive, animated portfolio with a mobile hamburger menu and a real
content dashboard (edit text and upload project photos without touching
code).

## What's new in this version

- **Mobile hamburger menu** — below 720px, the nav collapses into a ☰ button
  that slides open a full-width menu.
- **Fully responsive** — hero, stats, timeline, and project grid all reflow
  cleanly down to small phones (tested breakpoints at 820px, 720px, 420px).
- **Dashboard (Decap CMS)** — edit every section, including uploading a
  **photo per project**, from `/admin`.
- **Photo support** — each project card now optionally shows an image
  (screenshot, logo, etc.) uploaded through the dashboard.

## File structure

```
index.html          → page shell, content is rendered by js/main.js
css/style.css        → all styling, incl. mobile nav + responsive rules
js/main.js            → fetches content/data.json and renders every section
content/data.json     → all editable content (the dashboard edits this file)
images/uploads/       → where uploaded project photos land
admin/index.html      → dashboard entry point
admin/config.yml       → defines what's editable in the dashboard
```

## 1. Push to GitHub

```bash
cd mostafa-portfolio
git init
git add .
git commit -m "Portfolio with dashboard, mobile nav, and project photos"
git branch -M main
git remote add origin https://github.com/your-username/mostafa-portfolio.git
git push -u origin main
```

## 2. Connect to Netlify

1. https://app.netlify.com → **Add new site → Import an existing project**.
2. Choose GitHub → select this repo.
3. Leave **Build command** empty, **Publish directory** as `/`.
4. Deploy. You'll get a URL like `random-name.netlify.app` (rename later in
   Site settings → Domain management).

## 3. Turn on the dashboard

1. Site configuration → **Identity → Enable Identity**.
2. Identity settings → **Registration → Invite only**.
3. Identity → **Services → Git Gateway → Enable Git Gateway**.
4. Top-level **Identity** tab → **Invite users** → your email.
5. Open the invite email, set a password.

## 4. Use it

Go to `https://your-site.netlify.app/admin/`, log in, and edit any section —
including uploading a photo for a project under **Projects → [item] →
Photo**. Hit **Publish**, and the live site rebuilds automatically
(~30 seconds).

## Local preview

```bash
cd mostafa-portfolio
python3 -m http.server 8000
```
Open `http://localhost:8000` (opening `index.html` directly won't work,
since `fetch()` needs a real server, not a `file://` URL).

## Notes

- Project images are optional — cards without a photo just show the
  text content, no broken image icon.
- The animated network diagram in the hero (AWS/Docker/K8s/etc. nodes) is
  generated by `js/main.js` and isn't part of the dashboard — it's a fixed
  visual signature, not content.
- All animations respect `prefers-reduced-motion` for visitors who have that
  set at the OS level.
